## Adversarial QA pass (app-qa agent, same day)

Verdict before fixes: do not ship. Findings and what changed:
1. 721 to 1100 px product sheets collapsed (440 px figure column left ~200 px for text). Fixed: sheets stack below 960 px.
2. 320 px title blocks spilled across cell borders. Fixed: 2 x 2 title block on phones, values wrap.
3. 320 px proof strip: "opendxb" crossed into the next cell. Fixed: 26 px numerals on phones.
4. Phone nav unreachable with JavaScript off. Fixed: `<noscript>` shows the links.
5. 1 px horizontal scroll at 320 from a long button label. Fixed: buttons wrap.
Passed as-is: valid HTML, no duplicate ids, anchors resolve, external links noopener + new tab, alt text, no forbidden names or data, Arabic RTL isolates, keyboard, resume and App Store ids, site.js storage guards, static files.
Not checked by the agent: Arabic at phone widths (same CSS; verified by hand at 390 earlier), below-the-fold at 1440 (verified by hand).
